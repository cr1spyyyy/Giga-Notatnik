Polityka prywatności – Giga Notatnik

Aplikacja Giga Notatnik nie zbiera żadnych danych osobowych użytkownika. Wszystkie notatki, zdjęcia i nagrania głosowe są przechowywane lokalnie na urządzeniu użytkownika i nie są przesyłane na żadne serwery zewnętrzne.

Aplikacja nie wymaga logowania ani połączenia z internetem. Nie korzysta z usług zewnętrznych ani nie udostępnia danych osobom trzecim.

Aplikacja została opracowana jako projekt studencki w ramach przedmiotu Programowanie urządzeń mobilnych na Uniwersytecie Rzeszowskim.
